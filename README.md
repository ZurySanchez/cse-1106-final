# Smart Classroom comfort Monitor
Description

This project analyzes the temperature in the classrooms and decides if the temperature is in range. It gives a warning when the temperature is outside the range, in order for the classrooms to changes it. The range can be change based on the person or directors request.

Requirements

-Allow the  user to enter classroom temperature readings in Fahrenheit

-determine whether a temperature is within the acceptable range of 68F - 76F

-Display an appropriate NORMAL or WARNING status

-Calculate the average of the recorded temperatures

-Save temperatures readings and their statuses to a file

-Use an LED connected to the Raspberry Pi to indicate a warning condition

-Allow the acceptable temperature range to be changed according to the new requirements of a person
